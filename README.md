# Site public de PitchPlay

Deux pages, hébergées par GitHub Pages, que les boutiques exigent dans
la fiche de l'application :

| Fichier        | Sert de                          |
|----------------|----------------------------------|
| `index.html`   | URL d'assistance (Support URL)   |
| `privacy.html` | Politique de confidentialité     |

`privacy.html` est une copie de `pitchplay/store/privacy-policy.html`.
**Modifier l'original, puis recopier** — sinon les deux divergent et
c'est la version publiée qui engage.

Aucune ressource externe n'est chargée : ces pages ne contactent aucun
tiers, ce qui serait contradictoire avec ce qu'elles affirment.
